# TextMate grammars for the Android editor

Copied unmodified from Visual Studio Code 1.95.3 (`extensions/*/syntaxes`),
https://github.com/microsoft/vscode/tree/1.95.3/extensions, MIT (`VSCODE-LICENSE.txt`;
upstream grammar authors are credited in VS Code's ThirdPartyNotices).
`languages.json` maps the core's language ids (`appearance::editor_language`)
to them. Kotlin and TOML have no grammar in VS Code and stay plain.
