# Fonts bundled with the mobile apps

- `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf`: JetBrains Mono 2.304,
  from https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304, under the
  SIL Open Font License 1.1 (`JetBrainsMono-OFL.txt`). Unmodified.

iOS bundles them as resources (`UIAppFonts`); Android reads them as assets.
